# IRIS Executive Presentation Kit

This folder contains the complete executive presentation deck in **two ready-to-present formats**, along with all **1080p Full HD MP4 video snippets**, **companion screenshots**, and **rendered slide images**.

## 1. Ready-to-Present Executive Decks

| Deck File | Format | Best Used For |
|---|---|---|
| `IRIS_Executive_Presentation.pptx` | **PowerPoint / Keynote / Google Slides** (12 slides, 16:9 widescreen) | Native editable shapes, architecture diagrams, **embedded 1080p MP4 videos** on Slides 3 & 8–11, and full **Speaker Notes** in the Notes pane |
| `IRIS_Executive_Deck.html` | **Interactive Browser Deck** (12 slides, 16:9 widescreen) | Open directly in Chrome/Safari/Edge: press `F` for Fullscreen, `←` / `→` to navigate, click any video to play inline at 1080p, press `N` for Speaker Notes drawer, or `Cmd+P` to save as PDF |
| `deck_slides/slide_01.png` … `slide_12.png` | **1080p Slide PNGs** | High-resolution slide exports for quick sharing in Slack/Docs/Email |
